# Conference Scheduler — How to Use

## Installation

You don't need to install anything. Just download the file and you're ready to go.

### What You'll Get

**macOS:** `Conference Scheduler.app`
**Windows:** `Conference Scheduler.exe`

---

## Running the App

### macOS

Double-click `Conference Scheduler.app` and it will start.

Alternatively, drag it to your **Applications** folder first, then click it from there.

### Windows

Double-click `Conference Scheduler.exe` and it will start.

You can create a shortcut on your desktop if you want (right-click → Send to → Desktop (create shortcut)).

---

## What Happens

1. **A terminal window opens** showing the server starting
2. **Wait about 5 seconds** until you see a message like:
   ```
   ✅ Server is running!
   OPEN YOUR BROWSER AND VISIT:
   http://localhost:3000
   ```
3. **Open your web browser** and go to `http://localhost:3000`
4. You can now use the app!

---

## Using the App

Once the browser opens, you can:

- 📅 View the event schedule
- 👥 Manage participants
- ⏱️ Adjust time slots
- 💾 Save your changes

Everything you do is saved automatically.

---

## Stopping the App

**Easiest way:** In the terminal window, press `Ctrl+C`

**Alternative:** Close the terminal window with the close button (X)

---

## Troubleshooting

### "The app didn't open"

Try again. Sometimes it takes a moment to start up. If it still doesn't work:
- Restart your computer
- Delete the app and download it again

### "My browser didn't open"

Manually open your web browser and go to: **http://localhost:3000**

### "I see an error in the window"

This might be a temporary issue. Try:
1. Close the launcher window
2. Wait 30 seconds
3. Try again

### "Port 8000 is already in use"

Something else on your computer is using the same port. Try:
1. Restart your computer
2. Close other applications
3. Try again

### "It's running but nothing is loading"

Wait a bit longer. On first start, it can take 10-15 seconds to fully load.
